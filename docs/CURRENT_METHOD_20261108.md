# 当前路线与方法口径

本说明概述工作区 2026-11-08 的方法审查，不替代各次实验的冻结合同和最终审计。

## Self-play 工作线

来源与历史隔离、记忆检索和事件发现之后，通过 Planner、Gate、Realizer 构造并审计对话扩展；再进行出题、盲审、证据和重复检查、固定 Solver 评估、数据选择、训练及独立验证。不同实验并不一定执行了整条链，F/G 各轮的作者合同、结构和反馈条件需分别核对，不能把差异自动归因为单一反馈变量。

题面自然度与任务结构多样性分别检查。评估结构时，应比较实际所需的证据、关系和解题操作；一次排列变换不是一道语义独立的新题。已有训练效果和有限开发集结果不单独证明解决了过拟合，或证明反馈带来了因果收益。

## 来源审查口径

来源身份独立、题目实质重复和操作覆盖是三个不同层次。不得仅因宽泛重合、抽象操作族已见或存在未知历史记录就自动否决整个 root。未知保持未知，并针对相关重复线索检查；撤销错误的自动否决不意味着既有 HOLD 或 REJECT 自动通过。

一个目标可由局部信息或复述作答，不证明整个 root 无法支持其他有效目标。对声称需要跨会话的目标，应核验其关键证据、适用范围、答案和已发现的充分路径。简单但准确的题可以通过质量审查，但不能因此视为复杂结构增量。来源矛盾、身份混淆和无证据的因果绑定仍需具体复核。

不要求一个 root 的全部会话都对每个目标不可或缺，也不要求事件最终成功或完成；未完成状态和范围变化本身可以构成有效目标。以往在过严口径下得到的候选统计不能当作全部来源不可用的证明。新批次的合格数量必须按最新口径重新核对；本说明不授权生成或 Solver 调用。

## 外部评估输入

`external_eval/smoke_eval.py` 是独立的小样本评估工具，依赖用户提供 MultiRC 数据、BAMBOO 数据及模型。其 BAMBOO prompt 原始来源为 `https://github.com/RUCAIBox/BAMBOO` 的提交 `f230f206148396c12774ef3a632df291d96dc6ab`，原始 `prompt.json` 的 SHA-256 为 `efbefe0672c502a26dce4815dfe85fc6fbb6df752d87fec02faa1a97bd5a2d6d`。本包未核实该文件的再分发许可，不提供其副本；使用者应按上游条款自行获取。

历史 smoke 中的 `r1/r2` 模型标记与本轮训练模型命名不同，且该 runner 在支持时关闭 thinking。对比模型前应确认模型身份、prompt、输出协议、样本与分母一致，不把旧 smoke 结果误作本次 R2 的正式评估。
