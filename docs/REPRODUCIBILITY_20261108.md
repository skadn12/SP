## 绑定核验

`tools/verify_frozen_bindings.py` 可只读核对显式提供的 JSON manifest 中 `{path, sha256}` 绑定。它不运行项目代码或模型，也不输出文件内容；路径映射、相对路径基准、权限及缺失项仍需由使用者核实。它不能发现未写入 manifest 的动态依赖，也不能替代完整运行验证。

```bash
python tools/verify_frozen_bindings.py /absolute/path/LAUNCH_CONTRACT.json
python tools/verify_frozen_bindings.py /absolute/path/PROTOCOL_FREEZE.json --relative-base /absolute/path/run
python tools/verify_frozen_bindings.py /absolute/path/LAUNCH_CONTRACT.json --map /old/workspace=/new/workspace
```

输出包含有问题的文件路径，应按运行材料的敏感程度保存。多个 manifest 仅适合在路径基准一致时一起核对；每个路径都需要有明确 SHA-256。它不会递归打开绑定到的其他 manifest，需单独指定。
