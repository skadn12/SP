# 选择器按来源固定视图：合同补充审查草案

状态：`DRAFT_FOR_REVIEW`。本文件不修改既有计划、合同或执行包，不授权生成，也不是人工审批记录。下述来源范围规则与未知信息的选择优先级是两个独立问题；第二项必须先由用户选择并冻结，不能由控制器临时决定。

## 1. 问题与目标

`PLAN_ZH.md` 第 3、4 节要求固定历史基线，并依据历史覆盖增量选择目标；Stage B v3 合同同时要求检查当前 root 的历史重叠。当前匿名投影把 77 条同 root 附加记录放在一起，却没有经审计的来源关联，选择器因此无法知道哪些记录属于当前来源，尤其无法确定哪些 UNKNOWN 适用于本次比较。仅有记录总数和匿名 ID 无法解决这一问题。

下文提出一个用于审查的投影方式：历史基线固定一次，针对 8 个来源各产生一个固定视图；同一来源的 NEW_F 与 NEW_G 选择器看到相同的历史视图和选择规则。OLD 不新增选择器。视图提供历史语义编码，不提供历史题面、选项、答案、作者身份、F/G 分组或私有映射。

## 2. 来源范围规则：待审查的具体设计

每个来源的选择器历史视图包括：

1. **全局覆盖集：135 条封存训练记录。** 每条出现一次，只在资格和实际操作编码确已审计的范围内用于训练覆盖统计。各字段单独保留已确认或 UNKNOWN 状态，不用操作编码完成替代五维完成，也不将未知值当作未覆盖。
2. **当前来源的重叠集：77 条去重后的同 root 附加记录中，属于当前来源的子集。** 八个子集相互不重叠，按控制器侧 canonical candidate 身份核对后合计 77 条。它们是重叠参考，不因进入视图而成为合格训练覆盖；12 条不可恢复记录仍保留 UNKNOWN，不得凭 ID 猜内容。
3. **同源封存标记。** 全局 135 条中，与当前来源同 root 的记录须有匿名、可核验的本来源标记，以便与第 2 项一起构成同源比较集合。标记的映射只在控制器侧追溯至 canonical 身份；选择器只得到“本来源/非本来源/映射未知”的必要信息，不暴露 root 身份。若映射未知或标记与控制器审计不一致，应停止该视图的选择器调用，不静默当成非同源。

135 条仍作为全局覆盖全集；77 条附加记录不与其重复。同源重叠比较针对标记为本来源的封存行及该来源附加子集；覆盖频率针对合格封存行。不能把其他来源的附加历史作为本来源重复，也不能忽略当前来源未知记录。固定视图在任何本轮机会启动之前全部确定、哈希并冻结；批内不加入新题或别的机会的草案。

这是同一个不可变基线上的来源限定投影，不是八个各自变化的历史基线。同一来源两次 NEW 选择机会的视图内容及 hash 必须一致；选择器不知道 F/G，作者不获得历史视图。该投影方式需与原计划“同一份历史覆盖基线”的表述一起审查并明确记录，不能当作已有合同已批准的实施细节。

## 3. 未知信息的选择优先级：待用户选择

无论选择哪项，UNKNOWN、pending、provisional 和不合格记录都不是历史未覆盖的证据；不填猜测值，不声称完整历史去重。每个 slot 的可行性、已知相同/不同、无法比较的字段和未知对选择的影响均应被记录。本条讨论多个可行 slot 在历史比较不完整时如何排序，不改变事实可行性门槛。

待用户审定的备选策略：

- **A，保守停止：** 若当前来源未知记录或必要维度使目标的新颖性无法判定，则不据此选定目标，记录历史基线不足并停止该次选择。它最严格，但会降低可观察的首稿数量；这属于新增停止规则。
- **B，允许不确定目标：** 先按可行性及已知重复关系过滤，在不能可靠判定新颖性时明确标记 `UNKNOWN`，依据预先冻结的后续规则选出一个可行 slot；不得表述为历史未覆盖。需要用户进一步确定不确定 slot 与已知覆盖 slot 的相对顺序及可否使用覆盖频率。此项可能产出供后续审核的首稿，但不保证历史新颖。
- **C，未知与已覆盖同级：** 明确可验证未覆盖的目标优先；其余未知和已覆盖目标视为同一优先级，再按事先冻结的、适用于该级别的操作/证据关系频率及 slot ID 规则选择。须明确未知记录不参与覆盖频率的计算，且不能称未知目标为非重复。此项可能提高出题机会，但会改变原计划没有定义的未知情况下的排序。

以上均为待比较方案，不是已决定的路线。特别是 12 条未知记录若与某来源关联，仅从它们存在这一事实不能推断它们与某个 slot 匹配或不匹配。全局封存记录字段不完整时，涉及这些字段的频率与新颖判断也必须单独标明适用范围。

## 4. 原规则保持与拟补充之处

保持：8 roots、四组配对、OLD 全文探索后自行选目标、NEW 最多 3 个先冻结的语义 slot、独立选择一个、每机会至多一次、无替补重试；F/G 选择规则一致，固定基线不在批内更新；先核查来源和自然需求，再考虑历史覆盖、合格训练记录中的实际操作/证据关系频率，完全同级时按 slot ID；只回传所选 ID；首稿后统一盲审、结构核验、历史去重。既有题型和 F 卡不变，不按 Solver 分数挑选。

拟补充：明确全局覆盖集与逐来源重叠集的匿名投影及标记；保留字段级未知；冻结未知情况下的选择优先级和可用的频率分母；为这些规则提供来源映射、语义审查及 hash 证据。未知优先级可能导致新增停止条件或影响选择顺序，因此须作为合同补充明确记录，不能称作原规则已确定的行为。

## 5. 冻结前必要核验

- 控制器私有映射逐条核对 canonical candidate、源文件及原始字节 hash：135 条封存唯一；77 条附加唯一；已知 18 条封存重叠和 11 条派生副本正确去重；每条附加行恰属一个来源，缺失和冲突都阻断。
- 核对 8 个来源子集的并集恰为 77 条且两两不相交；本来源封存标记与私有映射逐行一致；12 条不可恢复记录有正确来源归属，未知字段及资格状态保持未知。
- 独立复核实际操作、五维字段、证据锚点和原始来源 hash。当前 65 条是已操作编码数，不等于五维完整数；已复核结果显示其中 31 条五维完整、34 条存在跨场景未知。封存 135 条中 49 条自然需求未知，另有字段待语义复核；不得补猜或以非空字符串代替审查。
- 对全部选择器可见字段做独立语义和隐私审查，防止复制历史题面、展示选项、答案、可恢复身份信息及场景/路径标识。正则和 hash 只能辅助，不能证明无语义泄漏。
- 核对全局 135 条实际资格和操作频率；仅允许已审计合格记录贡献相应已知维度，不让附加集、未知值或未审稿进入合格覆盖统计。
- 为每个来源生成并冻结单一视图；验证同源 NEW_F/NEW_G 的视图原始字节 hash 一致，其他身份、反馈卡、分组、作者日志及控制器映射不可见。核对输入、合同、状态机、调度、卡分配、selector 及 author 包的 hash，严格预检和角色隔离仍须全部通过。
- 冻结逐 slot 比较记录和选择理由的审计方式，分别记录已知匹配、已知不同与未知；核对停止/选择状态、固定 tie-break、单次调用和只回传 slot ID。审计记录不能宣称机械检查替代语义判断。
- 最终变更记录须绑定用户选择的未知策略、完整执行清单与最终 freeze hash；Stage A 审查与授权应据实际证据如实记录。预检通过本身不等于模型输出质量、历史完全去重或训练泛化。

## 6. 剩余风险

匿名视图仍可能通过语义内容间接揭示旧题或来源，必须单独审查；未知字段会限制新颖判断，即使生成了首稿也不能声称历史无重复。跨场景旧题缺少统一自然需求，不应为了凑齐五维而编造。8 个 root 的小试只能作探索性比较，固定反馈卡与单次采样的局限仍在。若采用任何未知情况下的新排序或停止策略，应在产生新结果前冻结并披露，避免按产出反向选择规则。
