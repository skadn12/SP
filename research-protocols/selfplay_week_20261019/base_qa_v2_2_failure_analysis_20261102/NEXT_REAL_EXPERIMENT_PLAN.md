# 下一轮 V2.2 有限真实实验计划（待确认，未启动）

## 1. 研究问题与事前判据

实验要区分三个问题：同范围来源是否供给自然 L3/L4；新 Discovery/选择能否识别这些关系；Construction 能否保留复杂依赖并形成合格题。不能只看最终PASS，也不能把材料/封包错误算成语义生成失败或 Solver 弱点。

主假设：在两个精确版本的允许范围内，能够找到并保留至少一个不可替代的跨场景关系操作。如果证据并不支持此假设，允许两个root都输出 `NO_SAFE_HARD_RELATION`。这应视为素材/能力边界的研究结果，不用反复出题凑通过数。

## 3. 固定预算与流程

使用这两个已有 roots；每root最多 **2道候选题**，总量不超过 **4道**，可以零题。每个root只做一次完整扫描和一次有限的跨场景定向复查，不展开多轮“搜索到通过为止”。候选关系没有强制数量，所有发现、拒绝与不确定假设都保留。

1. **预注册与来源冻结**：记录上述范围、SHA、正式许可、排除事实、rubric、预算、一次构造/审核规则，以及本次已知反例。不得把已看过这两个root称作未见测试集。
2. **Discovery**：读完整来源，归档事件/状态/身份及全部关系卡；显式查summary和替代路径。正式推导限定R02，实际难度旁路则覆盖全部将展示的parent/R01及题面：context-only里有直接答案不能靠“禁止引用”忽略。记录L0—L4及无效/不确定，不能只保留胜出的关系。
3. **选择冻结**：按资格和最简路线选择L3/L4；保留ranking receipt及低层拒绝原因。没有合格关系就NO_SAFE，不回退选局部计算。
4. **Gold/TARGET冻结**：在题型、题干、选项前冻结唯一语义、关键桥、必要组、替代路径和计算/排序约定。
5. **一次构造**：围绕自然需求选择题型；归档题干全部选项、干扰来源与错误机制；重新审题面条件下的最简路线。每个入选关系只构造一次，问题则HOLD，不在同题上重写直至PASS。
6. **送审前机械边界**：freeze读回后核验render contract、mapping、packet、外层code/prompt implementation manifest及实际交付材料；失败保留产物并停止该题。外层V2.2绑定不向内层V2.1严格receipt追加字段。它不占用一次正常语义盲答来测试损坏封包，也不自动重打包已送审题。
7. **独立隔离同模型盲答**：新的无继承作者上下文只看完整来源、允许/禁止范围说明、题干选项；看不到Gold、证书、预期难度标签与作者选择理由。先冻结原始盲答，再比较Gold；解析失败不得补字段或重问至成功。
8. **统一质量审核**：冻结盲答后才向质量审核阶段提供作者证书，逐项判定来源、身份、真实性、必要性、替代路径、Gold唯一、自然、干扰、捷径、难度、协议和计算/映射。可以沿用同模型隔离审核框架，不能声称独立模型交叉验证。争议进入人工复核。
9. **报告并停止**：保留PASS/HOLD/NO_SAFE及确切原因；不运行Solver，不训练，不修改扩充路线，不调用学校API。达到后续条件也仅提出建议，等待另行决定。

独立上下文是信息隔离约束，共享文件系统不是操作系统安全边界。需记录Reviewer实际获交的目录/packet及未访问私有文件的范围声明，不夸大隔离保证。

## 4. 每题与每root产物

每root至少保留实际作者输入、源版本/范围、全源扫描、事件ledger、全部关系与拒绝、补充假设、最简路径和选择记录。每题保留原始证据及来源、事件身份、最小充分集合、Gold推导、逐轮/语义组删除和全源替代路径、题干全部选项、干扰依据、捷径检查、TARGET/CANDIDATE/render冻结、Reviewer原始bytes、严格解析、比较和最终质量判定。

保留第一轮104814失配和103866题干预设案例作为回归负例；新实验不复用它们的raw来制造PASS，也不把以前被选中的局部算术改写成新的困难成果。

## 5. 指标与分母

| 指标 | 分母及解释 |
|---|---|
| 全部候选关系数、按root/等级/有效性分布 | 原始枚举数；枚举越多不自动越好 |
| 自然关系判断 | 报作者与独立审定，不把自然查询等同复杂关系 |
| 同范围L3/L4提名数及审定率 | 对L3/L4提名；必须排除更简可信路线 |
| 必要跨场景桥通过率 | 对声称存在桥的目标；报告删桥及全部替代支持结果 |
| summary/题面旁路发现数 | 对全部关系及成题分别报；明确降级和不确定 |
| 选择决策正确性 | 有高阶可用者是否进入构题；无者是否诚实NO_SAFE，不能靠重复候选抬指标 |
| Construction难度保留率 | 只有被冻结且审定为L3/L4的TARGET作分母；分母0写N/A，不能写0%或100% |
| Gold与联合必要性 | 生成候选为分母，数值/语义/唯一性分别报告；不以两组相加替代复杂桥 |
| 干扰、自然性、捷径 | 每题具体结果；静态flag与可唯一猜答的已证捷径分开 |
| 协议有效与正式Gold比较 | raw解析、来源资格、hash/mapping分别报；没有执行比较就不算一致 |
| 正式L3/L4 PASS数及root覆盖 | 全部质量审核与授权通过后才计入；低层题通过不计困难产出 |
| 失败归因 | 素材供给、发现覆盖、选择、构造、证书、资格、协议分别记录；可多原因 |

当前这两个root已被作者与复盘者看过，因此未来结果是**定向开发验证**，不是无污染泛化评估。相同来源范围可作描述性阶段对照，但prompt、代码与编排同时变化，不足以单独归因某一模块的因果收益。要证明泛化需另行确认未见素材和实验，不在本轮范围内追加。

## 6. 停止与后续建议

- 若来源不足，或最简路线均不超过L2：报告R02范围中的具体瓶颈，停止，不扩大工程或偷偷改source。
- 若发现L3/L4但选择/构造/审计失败：保存每个阶段卡片及首个失败，不重写同题至通过。
- 若少于两个root各至少一道正式L3/L4 PASS：不建议进入原设双root验收后的Solver阶段；说明剩余问题。
- 若至少两道正式L3/L4 PASS且来自两个root：只建议用户另行决定有限本地Qwen3-4B验证。结构难度与Reviewer答对不能证明Solver会错，更不能直接指导新扩充或训练。

本轮计划交付后停止。这里没有触发任何生成、Reviewer、Solver或训练任务。
