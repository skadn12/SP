# Run summary tools

`python3 final_summary_tools/summarize.py --check` reads inputs and prints integrity errors and unfinished solver batches. It writes nothing and never starts inference.

After all solver batches and per-candidate second-pass semantic reviews complete, `python3 final_summary_tools/summarize.py --export final_summary_tools/report_01` creates a new directory containing `ROOT_LEDGER.json` and `RUN_SUMMARY.json`. Existing directories are never overwritten. Integrity errors, incomplete solver outputs, or missing second-pass reviews block export. This is a review report, not a training export or an automatic final selection.

The ledger uses `adjudicated_increment_01` for its five candidates and the scope-adjudicated inputs for batches 05, 06 and 08. It records batch 04's independent pre-evaluation decisions alongside original quality records. It reads `semantic_review/second_pass/<candidate_id>.json` when available and preserves the complete review. Each comparison must have a reference candidate ID, a judgment of `fully_duplicate`, `overlap_but_distinct`, `distinct`, or `uncertain`, a nonempty reason, and `score_free: true`; the reference IDs must exactly match the packet without duplicates. Packet hashes and original reasons are retained for human review of substantive rationale, which this mechanical check cannot certify. A `fully_duplicate` judgment in either pass is retained as a flag, never automatically converted into a value judgment; eligible candidates with such flags or uncertain comparisons are marked `PENDING_SEMANTIC_FAMILY_ADJUDICATION`. Other eligible candidates remain `ELIGIBLE_PENDING_UNION_SELECTION`. The report does not claim that semantic family review is exhaustive or approve training.

The script verifies source and neutral-info hashes, evaluation input bindings, request/prompt/schema hashes, preflight counts, request matrices, raw-answer coverage and scoring counts. Raw answers remain in their original files; the ledger records their path, hash and request IDs. `input_sha256` contains the hashes of read inputs and validated bindings. It does not consume the damaged prior `FINAL_SELECTED_ITEMS.json`.
