# 新结构题小批对照实验 v140

本实验检验：在同一批完整对话上增加题目结构变化后，当前冻结模型的表现如何变化。只出题和评估，不扩充对话，不再训练。PLAN.json 在新题生成前固定选择、配额与修订预算。

## 样本与比较范围

按 v127 DEV 池 root_id 排序取前 4 个 root，不根据 Solver 分数挑选。每个 root 使用完全相同的完整 source，对应 3 道新多选、3 道新排序，以及复制的 1 道旧 Gold3 多选和 1 道旧排序。共计划 32 个题位：24 道新题、8 道旧题控制。原控制题的文字、选项、Gold、证据保留，记录 original_candidate_id；只为本实验增加题号和本地 source 路径。

这些 root 和旧题曾用于 DEV 生成、审核及 Solver 评估。新题为本次新写，不能把这些 root 声称为从未接触过的新测试 root。训练 root 与本次 DEV root 的身份检查仍需执行。未使用 TEST root。

新多选 Gold2、3、4、5 各计划 3 道；每道含六个不同命题。新排序每个 root 的场景计数预定为 [3,2,1]、[2,2,2]、[4,2]。排序仍按指定场景中原文出现顺序，保留同轮子句从左到右规则；不更改成实际事件发生时间。多项来自同场景后，单凭场景编号不足以推出完整排列。

## 制作与入选

由当前会话的不同任务作者基于完整 source 编写，确切底层 Codex 模型 ID、逐调用 token 用量均不可得，记为未知，不虚构 API 模型标识。多选需要正项明确支持、负项明确矛盾，不以没有提到代替矛盾。声明跨轮必要时，要解释每个必要证据的作用，不以多引几句代替必要性。排序先保存锚点计划，再写题项，保留人物、转述者、否定、计划或完成状态；列出公开范围内所有合理替代提及并检查顺序唯一。

审核任务先只读公开题和完整 source，保存自行重建的标签或锚点，再对比私有答案。不同任务仍使用共享继承模型和共享文件系统，是内部任务分工审核，不声称外部人员独立性或访问控制保证的盲审。保留实际读取过程和作者、审核者标识。

每个题位只有一份原始草稿，最多允许一次根据内容审核进行修订。原稿、失败原因、修订和复审都保留。不能在看到 Solver 表现后修题或替换题位，也不能暗改原 Gold 或锚点来挽救原稿。审核未过的题保留在 32 个计划题位的分母中，单独报告，不能悄悄补题。旧控制来自此前已入选池，本次做证据和格式复验，并明确区分复用与新作。

机械入选检查包括 source SHA、完整六项证据、原文引文精确匹配与说话者一致、Gold 与标签关系一致、排序锚点无重叠且与 Gold 一致、题号唯一、公开数据无答案字段。语义审核另行检查，机械门槛不能替代语义正确性。

## 冻结与推理

入选池在任何本次 Solver 推理前冻结。使用已有完整合并权重 M_clean_policy 与 M_v125_newonly，不再叠加 LoRA，不评估 Base。沿用原生 v15 full-context 协议和评分：多选 6 个不同排列，每排列 3 次采样；排序 12 个不同排列，各 1 次；种子 2026100800。两模型采用同一请求列表、解码设置及 batch8 调度。若 32 题全部入选，每模型 480 次，共 960 次。完整对话输入，不截断。

模型、代码、输入、Gold、排列映射与请求在推理前绑定 SHA；独立任务复验预检后才运行。保留原始响应和解析结果；不自动重试，不按结果筛题。数值完全等同于逐条推理不是本实验的主张。

## 报告与限制

报告题目等权的全对率与 signed partial；排序另报成对顺序正确率。无效或缺失调用保留计划调用分母，并记全对为 0。分别按新旧题、题型、Gold、root 汇总，报告入选率、修订数、拒绝数和审核分歧。独立任务从原始响应重算结果。

旧多选控制均为 Gold3，新多选包含 Gold2至5，因此不把 pooled 新旧差值当成仅由结构导致的因果效应；应同时报告 Gold3 层以及同 root 题型对比。只含 4 个 root，同 root 多题和同题多排列相关，属于描述性小批诊断，不能据此证明大规模生成稳定、反馈有效或泛化充分。旧题和新题的证据、内容和词汇也可能不同。
